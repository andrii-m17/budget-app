# Чекліст перевірки зміни вигляду (iPhone PWA)

Позначай кожен пункт: ✓ / ✗ / н/д. Розбіжність із макетом чи HIG описуй, не виправляй мовчки.

## Розкладка й дотик
- [ ] Цілі дотику ≥ 44×44 pt (мінімум 28×28 лише з причиною); відступ ≈ 12 pt між сусідніми
- [ ] Вміст не під статус-баром, Dynamic Island, таббаром; `env(safe-area-inset-*)`; `viewport-fit=cover`
- [ ] Ширини 290, 320, 360, 390, 440: без горизонтальної прокрутки, без накладання
- [ ] `dvh` замість `vh` для висоти екрана (або узгоджена причина)

## Текст і колір
- [ ] Розмір ≥ 11 pt; основний ≈ 17 pt; поля вводу ≥ 16 px
- [ ] Довгі підписи переносяться (немає обрізання, що ховає зміст)
- [ ] Контраст ≥ 4,5:1 (≥ 3:1 для жирного й великого), обидві теми
- [ ] Зміст не лише кольором (є текст/піктограма)

## Поведінка
- [ ] Жест має альтернативу без жесту
- [ ] Шторка: один спосіб закриття очевидний, свайп вниз, підтвердження при незбережених змінах
- [ ] Деструктивні дії: підтвердження лишається (рішення Андрія 22.10.2026, як у Apple Фото); «скасувати» замість підтвердження не впроваджуємо
- [ ] Цілі < 44 pt розширюються невидимим `::after`, без зміни вигляду (`scripts/tap-targets.mjs`)
- [ ] Порожній стан пояснює чому порожньо
- [ ] Не ховати й не вимикати таббар без пояснення

## Рух
- [ ] Анімація коротка, переривна, не блокує дію
- [ ] `prefers-reduced-motion` / `motionReduced()`: без зсувів і масштабу, лише затухання
- [ ] Рух не єдиний носій інформації

## Сповіщення
- [ ] Текст стислий, без імені застосунку й чутливих даних у прев'ю
- [ ] Не дублює; не шле про те, що видно у відкритому застосунку
- [ ] Показ негайний (iOS вимагає), журнал не блокує показ

## Платформа
- [ ] Не повторює відомі невдалі спроби з `docs/ROADMAP.md` (матриця «вже випробуваного») і `docs/PLATFORM_LIMITS.md`
- [ ] Перевірка на реальному iPhone описана в звіті
