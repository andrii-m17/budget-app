# Звіт про задачу

Два виходи: **повний** звіт за шаблоном нижче пишеш у `docs/reports/<код>.md` (Notion не використовується); **чату** даєш чату — стільки, скільки потрібно для рішення, без повторення контексту (класи A і B зазвичай до ~25 рядків, клас C і дослідження до ~60): зроблено, тести, відхилення, відкриті питання, чи запушено.

Звіт читає чат (приймає роботу) і користувач (вирішує й перевіряє на iPhone). Однаковий формат скорочує уточнення. Пиши коротко: факти, числа, без переказу ТЗ.

## Шаблон (завжди цей порядок)
```
## Підсумок
1–3 речення: що зроблено або чому зупинився.

## Ревізії
| Rev | Коміт | Що |
|---|---|---|

## Перевірено
Як саме і чим (тести: N пройшли / M усього; preview; вимірювання з числами; скріншоти: шляхи файлів).

## Не перевірено / ризики
Чесно: що не вдалося перевірити, де можлива регресія.

## Відхилення від ТЗ
Що зроблено інакше й чому. Якщо ТЗ суперечило макету: що обрано.

## Запити до чату
Серверні зміни, рішення, яких бракує (або «немає»).

## Перевірка на iPhone
Конкретні кроки й очікування (також додано в qa.json).

## STATUS
+ Додано: ...
✓ Закрито: ...
⏳ Чекає: ...

Сесія: /clear   (або: /compact (ключове збережено в docs/reports), якщо клас C посередині і контекст ≈ 50–60% за /context)
```

## Правила
- Не нагадуй пунктів із розділу «Закрито» в `docs/STATUS.md`.
- Числа замість оцінок («висота 139 пт», «запитів 55 → 5»).
- Якщо зупинився (розбіжність, клас C): секції «Ревізії» й «Перевірено» можуть бути порожніми, але «Запити до чату» обов'язкові.
- Кожен звіт закінчується рядком «Сесія: /clear» (задачу завершено) або «Сесія: /compact (ключове збережено в docs/reports)» (клас C посередині, контекст ≈ 50–60%).
- Не вигадуй успіх: якщо не перевіряв на справжньому пристрої, так і пиши.
- Перевірка за ризиком (рішення власника 22.10.2026): у звіті клас A: лише автотести; B: один знімок «до/після» (темна тема, 390 pt) і один `spec-reviewer`; C: тести й сценарії на моку + один `spec-reviewer`, без знімків, якщо вигляд не змінюється. Якщо знімок не вдався: «знімок X не отримано, причина Y» (одна повторна спроба, двічі поспіль не повторювати, запропонувати вимкнути); це не блокує задачу.
