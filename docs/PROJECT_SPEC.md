## 0. Архітектура файлів (з Rev 2.3.3 — важлива зміна)

До Rev 2.3.3 застосунок був буквально одним HTML-файлом без збірки. Повноцінний PWA
(service worker, офлайн-доступ, «Додати на головний екран») технічно вимагає окремих
файлів — service worker не можна вбудувати інлайн у HTML, а маніфест має бути окремим
файлом, на який посилається `<link rel="manifest">`. Тому деплой тепер — це набір файлів
у корені репозиторію (GitHub Pages):
```
index.html      — сам застосунок (те, що раніше було єдиним файлом)
manifest.json   — назва, іконки, display:standalone
sw.js           — офлайн-кеш (мережа-спочатку для index.html, кеш-спочатку для решти)
icons/          — icon-192.png, icon-512.png, apple-touch-icon.png
```
`localStorage`, довідники, уся бізнес-логіка — без змін, лишаються в `index.html`. Локальне
використання (`file://`, без хостингу) і далі повністю працює, просто без PWA-частини
(service worker програмно не реєструється на `file://` — обмеження безпеки браузера).

## 1. Загальна структура застосунку

Локальне збереження в `localStorage`, імпорт/експорт через Excel (SheetJS). Український
інтерфейс, ₴, дати — локальні (безпечно, без `toISOString()`).

### Навігація (5 розділів)
Аналітика · Облік · Витрати · Структура · Сервіс — плюс «Налаштування» окремим drawer
(розділювач, не таб).

- **Desktop (≥1280px)** — sidebar зліва, контент праворуч.
- **Tablet (768–1279px)** — нижня tabbar, сітки на 2 колонки.
- **Mobile (<768px)** — нижня tabbar, одна колонка. «Витрати» — виділена кнопка по центру
  tabbar/sidebar (кольорове заповнення, як «+» у типових застосунках), бо це єдина щоденна
  дія — тепер додатково прискорена автофокусом і автопідказкою (розділ 4).

### PWA-поведінка
- «Додати на головний екран» відкриває застосунок у standalone-режимі (без адресного
  рядка браузера).
- Офлайн-доступ після першого онлайн-відкриття (service worker кешує app shell).
- iOS Safari отримує окремі мета-теги (`apple-mobile-web-app-*`, `apple-touch-icon`), бо
  `manifest.json` там і досі враховується лише частково.

## 3. Вкладка «Облік»

- **Дохід за місяць** — 3 фіксовані джерела, upsert по джерело+місяць.
- **Борги по картках** — керований список банків, pre-fill з попереднього місяця
  (курсив/пунктир, зникає при редагуванні).
- **Оплати частинами (ОЧ)** — два поля на рядок (Залишок + Платіж/міс), обов'язкова
  «Початкова сума» при створенні. Модель C (Rev 2.2.x): очікуваний залишок рахується
  зі статистичної моди історичних платежів або суми прив'язаних витрат (якщо є),
  розбіжність факт/очікування — інформаційне попередження з кнопкою «Застосувати».
- **Автозв'язок витрата↔ОЧ**: Метод B (кнопка «Оплатити цю ОЧ» в кожному рядку ОЧ) і
  Метод C (підказка за збігом тексту назви витрати, з чіпами при кількох кандидатах).
- **Захист незбережених змін**: тихий тег «⚠ не збережено» біля рядка, кастомна модалка
  підтвердження при спробі змінити місяць/вкладку з незбереженими змінами в Обліку.
- Видалення банку/ОЧ — модалка з вибором місяця «Приховати з...».

## 4. Вкладка «Витрати»

- **Форма «Нова витрата»** — компактна на desktop, на всю ширину на mobile. Прогресивне
  розкриття категорії/підкатегорії з захистом ручного вибору.
- **Автопідказка назви за історією (Rev 2.3.5)** — власний спадний список під полем
  «Назва» (не нативний `<datalist>` — ненадійний на iOS Safari), підрядковий пошук від
  2 символів, до 6 варіантів, сортування за частотою+свіжістю, поруч показана категорія
  останнього запису з такою назвою. Вибір (тап або Enter при підсвіченому варіанті)
  підставляє назву й категорію/підкатегорію з реальної історії саме цієї назви
  (пріоритетніше за загальний словник автокатегоризації) і переводить фокус на «Сума».
- **Автофокус (Rev 2.3.4)** — при вході на вкладку курсор одразу в «Назва витрати»
  (або в «Сума», якщо форма вже заповнена з відновленої чернетки). Синхронний виклик
  `focus()` без затримки — вимога iOS Safari для програмного відкриття клавіатури.
- **Автозбереження чернетки (Rev 2.3.2)** — форма зберігається в окремому
  localStorage-ключі на кожен ввід; відновлюється при наступному відкритті застосунку,
  якщо запис так і не був збережений. Нейтральна підказка «Відновлено незбережений
  запис» з кнопкою «Очистити». Автоматично зникає після успішного «Додати витрату».
- Дата: стрілочки ±1 день, підпис повною українською датою, персистентна між
  збереженнями (скидається на сьогодні лише при вході з іншої вкладки — і лише якщо
  немає незбереженої чернетки з іншою датою).
- Enter у будь-якому полі — зберігає запис (окрім випадку, коли підсвічена підказка
  автодоповнення назви — тоді Enter вибирає її, не сабмітить форму).
- Поле суми — розділювачі тисяч.
- **Журнал** — згруповано по днях, тап-виділення + інлайн-редагування, підтвердження
  перед видаленням.

## 6. Вкладка «Сервіс»

- **Резервне копіювання (Rev 2.3.1)** — «Зберегти бекап» / «Відновити з бекапу»: повний
  знімок усього стану застосунку (витрати, доходи, борги/ОЧ, `hiddenFrom`, усі
  довідники) одним JSON-файлом, окремо від Excel-експорту нижче. Валідація тегом
  `__budgetBackup`; відновлення повністю замінює поточні дані з попередженням через
  кастомну модалку (незворотно).
- **Експорт в Excel** — аркуші «Витрати», «Доходи», «Борги» (часткова проекція для
  сумісності з основним файлом Андрія — не заміна повного бекапу).
- **Імпорт з Excel** — аркуші «Витрати», «Історія», «Фінанси» (детально по ОЧ), з
  діагностикою по кожному рядку після імпорту.
- **Очистити все** — підтвердження через кастомну модалку.
- **Діагностика даних** — «незабаром» (не реалізовано).

## 7. Design System

*(без змін — кольори, типографіка, компоненти, кастомна модалка `#app-modal` як єдиний
перевикористовуваний компонент; технічний борг щодо її ускладнення зафіксовано в
STATUS.md)*

Додано з Rev 2.3.x:
- **`.name-suggest-list`** — спадний список автопідказки назви витрати, той самий
  візуальний мова (border/shadow/radius), що й кастомна модалка, але позиціонований
  відносно поля (`position:absolute`), не по центру екрана.
- **`.field.draft-hint`** — нейтральний (сірий, не зелений/фіолетовий) блок-підказка про
  відновлену чернетку — свідомо інший тон, ніж auto-hint (категорія) чи
  installment-link-hint (ОЧ), щоб не плутати типи підказок між собою.
