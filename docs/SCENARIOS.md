# Сценарії: що обов'язково продумати перед зміною

## Осі
| Вісь | Значення |
|---|---|
| **Обсяг даних** | 0 · 1 · кілька (3–5) · типовий місяць (~120 витрат) · великий (5 000 витрат, 3 роки) · екстремальний (20 000, довгі назви) |
| **Якість даних** | відсутні поля · невірні типи · дублікати · конфлікт двох змін · посилання на видалену категорію/рахунок · надгробки · приховано з місяця · майбутні дати · сума 0 / від'ємна / 2 147 483 647 · емодзі й довгі назви · HTML-подібний текст |
| **Пристрій і ввід** | iPhone PWA (головне) · iPhone Safari · iPad портрет/альбом · десктоп ≤ 768 і ≥ 1280 · дотик / миша / клавіатура (Tab, Enter, Esc) · екранна клавіатура iOS у шторках |
| **Відображення** | темна/світла тема · збільшений текст · зменшення руху · VoiceOver |
| **Мережа й синхронізація** | офлайн · повільно · обрив посередині · повернення з чергою · два пристрої одночасно · видалення на іншому пристрої (м'яке й остаточне) · пропущена подія Realtime · вихід/вхід |
| **Час** | перехід місяця й року · північ · літній/зимовий час · Київ · 29 лютого · `due_day` 30/31 у коротких місяцях |
| **Сповіщення** | вимкнені · тихі години · дозвіл відхилено · застосунок закритий / у фоні / відкритий |
| **Стан застосунку** | холодний старт · повернення з фону · оновлення версії (SW) · порожній кеш |

## Мінімум за типом зміни
- **Вигляд (A/B):** обсяг 0 / 1 / багато, довгий текст, обидві теми, iPhone + iPad + десктоп, зменшення руху.
- **Логіка й дані (B/C):** якість даних, обсяг (включно з великим), час, офлайн.
- **Синхронізація (C):** мережа, два пристрої, видалення (м'яке й остаточне), вихід/вхід, повернення з фону.
- **Клавіатура (C):** усі шторки, що зачеплено, iPhone PWA; перевірка лише на пристрої + лог діагностики.

## Тестові набори даних (синтетичні, `tests/fixtures/`)
`empty` · `one` · `typical` · `large` (5 000 витрат) · `invalid` · `hostile` (XSS-рядки, 200-символьні назви, емодзі) · `edge-dates` · `two-devices` (сценарій конфліктів для моку). Завантажуються лише в тестовому середовищі (`?fixture=<назва>`), ніколи в робочій базі.
