# KB-RESUME-8 · клас ризику C (дві ревізії)

Навички: rev-release, task-report, scenario-matrix, step0-audit, ios-keyboard-safety. Субагент: spec-reviewer. Макет не потрібен.

## Мета
1. Повторний вихід з застосунку без закриття клавіатури після повернення не дає зсуву.
2. «Піднята шторка» (keep-lift) стає звичайною поведінкою без перемикача; варіант proxy-tap прибирається разом із кодом.

## Факти (MT-1126-6193, Rev 2.32.438)
- 5 повернень: keptLift true 5/5, підйом 252–269 мс, 14–16 кадрів, jumpMax 52–53, touchDuringLift 0, kbShownMs 159–198; panMax 0 у 4/5.
- Виняток: «Термін», повторний вихід одразу після повернення (клавіатура не закривалась, шторку збільшено на 46): keep-enter з liftMore 0, panMax 44.
- Причина: kbKeepEnter міряє fieldCenter при застосованому kbKeepGrow (+46) → plan.extra 0 → kbKeepGrowApply спершу викликає kbKeepGrowClear() → шторка коротшає, поле опускається, зсув iOS ≈ 44.

## Рішення користувача
Поведінку 2.32.438 лишаємо; keep-lift — типова без перемикача; proxy-tap прибрати.

## Крок 0 (стоп і короткий звіт)
1. Тест повторного входу, що падає на поточному коді (центр поля після входу ≠ centerTarget ±1).
2. Усі місця залежності від kb-resume (control/proxy-tap/keep-lift) і що лишиться від control (kb-bg-reset).
3. Що зі збереженим у localStorage варіантом і групою «Експерименти».

## Rev 2.32.439 — виправлення повторного виходу
1. У kbKeepEnter спершу kbKeepGrowClear, потім міряти й рахувати план (або віднімати застосований grow) — спосіб обрати в Кроці 0; центр після входу = centerTarget ±1.
2. Самописець: у keep-enter поле growBefore (pt).

## Rev 2.32.440 — keep-lift за замовчуванням
1. Прибрати перемикач kb-resume з TEST_VARIANTS, kbResumeVariant()/kbResumeDecide(), гілки proxy-tap (замінник, KB_RESUME_PROXY_MS); kb-bg-reset лишається.
2. Збережене значення ігнорується й прибирається (pruneVariants); група «Експерименти» ховається, якщо порожня.
3. Самописець kb-resume і kb-resume-lift лишаються (variant 'keep-lift' або без поля — обґрунтувати); REC_ALLOWED_* узгодити.
4. CODE_MAP, STATUS, ROADMAP («матриця вже випробуваного»: proxy-tap — клавіатура з першого дотику, але стрибок 319; await-focus — з другого дотику).

## Не робимо
Підйом, щит, умову входу (blur-snap ≤ 3 с), криву, вигляд піднятої шторки (KB-RESUME-4b), інші експерименти.

## Критерії (телефон)
X1: 3 повторні виходи поспіль: panMax ≤ 5, клавіатура з першого дотику. X2: звичайні повернення як у 2.32.438. X3: у «Експериментах» немає «Підняти шторку»/proxy-tap.

## Тести
Повторний вхід (червоний до 439, зелений після); 3 рази поспіль стабільний план; після 440: немає proxy-tap/kb-resume у TEST_VARIANTS, збережений control/proxy-tap → keep-lift, приватність ключів, node --test, kb-resume.spec, keyboard.spec (без 44), e2e:smoke. iPhone: 3 повторні виходи на «Термін»; 2 звичайні на сумі доходу; 1 вихід без клавіатури.
