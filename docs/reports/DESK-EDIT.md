# DESK-EDIT (Rev 2.32.142): парність десктоп/мобільна

Причина: з Rev 2.32.44 тап по рядку витрати нічого не робить, редагування лише свайпом (touch-події); мишею недосяжне.

| Де | Мобільна | Десктоп до | Десктоп після |
|---|---|---|---|
| Витрата в «Журнал» / короткому списку | свайп → «Редагувати» | **не працювало** (лише свайп) | клік, Enter/Space (виправлено) |
| Витрата: видалення | свайп, кнопка ✕ | кнопка ✕ працює | без змін |
| Дохід у Журналі | редагування немає (за дизайном, startEditRecord лише для витрат) | так само | без змін; редагується в «Облік → Доходи» |
| Доходи (Облік) | тап по рядку `onclick` | працює (кнопка) | без змін |
| Борги / картки | тап по рядку `onclick` | працює | без змін |
| ОЧ | тап по рядку `onclick` | працює | без змін |
| «Вхідні» (Mono): деталі | тап → шторка | клік → шторка, працює | без змін |
| «Вхідні»: «Додати»/«Ігнорувати» | свайп і шторка | у шторці, працює (свайп-кнопки недосяжні) | без змін |
| «Видалені дані» | тап → деталі; свайп Відновити/Видалити назавжди | клік → деталі, кнопка «Відновити» на рядку, «Видалити назавжди» у деталях; працює | без змін |
| Сповіщення: видалення рядка | свайп | недосяжне мишею | Rev 2.32.143 (кошик) |
