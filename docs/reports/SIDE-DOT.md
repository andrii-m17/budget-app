# SIDE-DOT — Rev 2.32.126 (клас B; не запушено)

## Причина
У боковій панелі (десктоп) правило `.side button.side-tab svg { 18px }` (специфічність 0,2,2) перебивало `.avatar-status-dot svg` (0,1,1): гліф синхронізації 18px вилазив з крапки 11px. Крапка була пів-аватара (11 з 22 px; на мобільній 11 з 36) і мала кільце кольору `--color-surface` на темнішому тлі панелі.

## Зміни
- Лише CSS у боковій панелі: крапка 8px, кільце 1.5px кольору `--color-bg`, гліф 70% крапки (≈3.5px). Мобільна крапка без змін.
- Тест `tests/side-avatar-dot.test.js` (+2).

## Перевірка на пристрої
- Не потрібно: зміна лише для десктопа (бокова панель з'являється від 768px). Мобільний аватар у шапці не змінено.
