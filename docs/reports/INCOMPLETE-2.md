# INCOMPLETE-2 — Rev 2.32.135 (клас C; не запушено)

Рішення чату: незалежні причини; «Заповнити» підсвічує всі порожні поля; після збереження лишається тільки те, що бракує. Вигляд модалки (рядки з іконкою й значенням справа) без змін.

## Критерії
| Об'єкт | Порядок і поле | Неповне, коли |
|---|---|---|
| Картка | Кредитний ліміт | ліміт не більше 0 |
| | Борг за місяць | немає запису за місяць або борг порожній |
| | Мінімальний платіж | не внесено при боргу більше 0 **або невідомому** («залежить від боргу»); при боргу 0 не потрібен |
| | День платежу | `paymentDay` порожній (раніше не вимагався) |
| ОЧ | Дата платежу | `dueDay` порожній |
| | Початкова сума | не більше 0 |
| | Залишок за місяць | немає факту й оцінки (раніше не перевірявся) |
| | Платіж на місяць | не більше 0 при залишку більше 0 **або невідомому** («залежить від залишку»); при залишку 0 не потрібен |
Приховані картки й ОЧ без причин, як раніше.

## Зміни
- `incompleteDetails` (причини з `dependent`) замість «заглушення» взаємовиключних причин; `incompleteReasons` лишилась обгорткою (коди).
- Модалка показує всі причини; для умовних при невідомому борзі/залишку значення «залежить від боргу / залишку».
- `fillIncomplete(kind, i, codes)` підсвічує всі порожні поля відразу (до вводу в поле або 6 с), прокручує до першого; без автофокусу (клавіатурна логіка шторок не чіпається); поле дня платежу картки — `cdd-payday`, залишку ОЧ — `idd-balance`.
- Після збереження перелік перераховується з даних: показується лише те, що лишилось; повторне питання без причини неможливе (крапка зникає).
- Вплив: крапки тепер з'являться й у карток без дня платежу та ОЧ без залишку за місяць (за рішенням чату).

## Матриця сценаріїв
| # | Сценарій | Очікувано | Перевірка |
|---|---|---|---|
| 1 | картка без усього | ліміт, борг, мін. платіж («залежить від боргу»), день платежу | unit |
| 2 | картка з боргом без мін. платежу | лише мін. платіж | unit |
| 3 | картка з боргом 0 без мін. платежу | без причини | unit |
| 4 | нульовий/порожній ліміт | limit | unit |
| 5 | ОЧ без залишку | дата, початкова сума, залишок, платіж («залежить від залишку») | unit |
| 6 | ОЧ із залишком без платежу | лише платіж | unit |
| 7 | прихована картка/ОЧ | без крапки | unit |
| 8 | «Заповнити» | підсвічені всі порожні поля, перше в зоні видимості | preview (мок): виконано, підсвічено всі чотири поля картки |
| 9 | після збереження | лише решта причин | перерахунок із даних; iPhone |
| 10 | клавіатура | без автофокусу, `kb-*` не чіпались | unit (немає `.focus(`) |

## Для iPhone
- «Облік» → «Борги»: крапка на картці без усього відкриває модалку з чотирма рядками, у «Мінімальний платіж» значення «залежить від боргу»
- «Заповнити»: шторка відкривається з підсвіченими всіма порожніми полями, клавіатура сама не з'являється
- Після збереження боргу: крапка й модалка показують лише те, що ще бракує, а коли все заповнено крапка зникає
