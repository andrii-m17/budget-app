# RESTORE-DUP — Rev 2.32.134 (клас C; не запушено)

## Причина
Додавання слова перевіряє дубль лише серед живих (`!d.deletedAt`), тож за час, поки категорія/підкатегорія була видалена, така сама ключова фраза могла з'явитись деінде. `restoreCategory`/`restoreSubcategory` повертали каскадні слова без перевірки (перевірка була лише в `restoreBlockedReason` для окремо видаленого слова) → два активні слова з однаковим текстом.

## Зміна
`restoreCascadedWords(marker, belongs, nowISO)`: слово з текстом, що вже є серед живих (враховуючи вже повернуті в цьому ж проході), не воскрешається; щоб воно не лишилось невидимим (маркер каскаду ховає його зі списку, а категорія вже активна), маркер знімається, воно стає окремим видаленим словом у «Видалених даних» (відновлення заблоковане, доки дубль існує; можна видалити назавжди). Результат відновлення має `skippedWords`; тост «N слів не відновлено: вони вже існують» (warning) після «Запис відновлено».

## Матриця сценаріїв
| # | Сценарій | Очікувано | Перевірка |
|---|---|---|---|
| 1 | дубль слова при відновленні категорії | дубль не повертається, решта повертається, skippedWords=1 | unit |
| 2 | дубль при відновленні підкатегорії | те саме | unit |
| 3 | без дубля, повне відновлення | усе повертається, skippedWords=0 | unit |
| 4 | два каскадні слова з однаковим текстом | повертається одне, одне пропущено | unit |
| 5 | пропущене слово далі | видиме як окреме видалене слово; відновлення блокується «слово вже існує» | unit (маркер знято) + наявна `restoreBlockedReason` |
| 6 | окремо видалені слова/підкатегорії | не чіпаються (як раніше) | наявні тести |
| 7 | два пристрої | `updatedAt` слів бампається, LWW як для решти зміни довідника | не змінено |
| 8 | офлайн | локальна зміна, синхронізація пізніше, як раніше | не змінено |

## Для iPhone
- Дублі при відновленні: видалити категорію зі словом, додати таке саме слово в іншу категорію, відновити категорію, з'являється тост «1 слово не відновлено: воно вже існує», у «Структурі» лише одне таке слово
- Пропущене слово в «Видалених даних»: видно окремим рядком, «Відновити» пояснює, що слово вже існує
