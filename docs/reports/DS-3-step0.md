# DS-3 · Крок 0: таббар і шапка (клас C, без змін коду)

Джерела: макет `docs/ui/mockups/analytics-ds/index.html`, розділ 2 `docs/specs/DS-PLAN.md`, код `index.html` (розмітка таббару ~954–975, шапка ~163–200), `css/app.css` (таббар ~2069–2409, `.main-col` 57, `.month-pill` 201), `js/shell.js` (`switchTab`, `performSwitchTab`, `initSideNav`, `updateTabBubble`, `updateScrollTopBtn`, press-feedback з `PRESS_EXCLUDE`). Дані синтетичні, реальних сум і назв немає.

## 2. Взаємодії й ризики

| Область | Ризик | Як знімаємо |
|---|---|---|
| Таббар при відкритій клавіатурі | правила `kb-*` (css ~2204/2219/2229) ховають або зсувають таббар; стиснення «mini» не повинно з ними конфліктувати | `kb-*` не чіпати; mini вмикати лише класом, який не перетинається з `kb-*`; E2E: клавіатурні тести 38–39 і набір таббару |
| Safe-area (Баг 1a) | відступ від низу залежить від `env(safe-area-inset-bottom)`; зміна висоти капсули зсуне формулу | висоту в стані mini міняти лише через `transform: scale`, відступ не чіпати |
| Наявні обробники прокрутки | `updateScrollTopBtn` на `#main-col`; ще один слухач для mini і шапки має бути пасивний і один на всі потреби | один rAF-слухач, спільний для капсули, mini і компактної шапки |
| iPad (бічна панель) | `initSideNav` перебудовує таббар у бічну панель; mini і «бульбашка» там мають бути вимкнені | mini лише в режимі нижнього таббару |
| `prefers-reduced-motion` | власні keyframes іконок, бульбашка, стиснення | один блок `@media (prefers-reduced-motion: reduce)` вимикає все, крім зміни кольору |
| Навантаження blur під час прокрутки | повторне розмиття великих шарів; історія: 2.4.21 → 2.4.22 прибирали blur через мерехтіння | не додавати нових blur-шарів; капсула шапки використовує вже наявний `--glass` без додаткового `backdrop-filter` на прокручуваному елементі; перевірити на iPhone |
| Історія мерехтіння | `will-change` на `.tabbar-glass` додано свідомо | не прибирати; анімувати лише `transform`/`opacity` |
| Native `<select>` місяця | на iOS дає системний барабан | заміна на скляний список; `<select>` лишається прихованим для доступності й тестів до погодження |
| Поля вводу | нових текстових полів не додається | `id` не потрібні |

## 3. Іконки

| Вкладка | Контурна | Заповнена | Потрібно |
|---|---|---|---|
| Аналітика | є | немає | суцільна діаграма із сектором, що росте й повертається |
| Облік | є | немає | заповнене коло з білим «+» |
| Структура | є | немає | вузли, що з'являються по черзі |
| Сервіс | є | немає | зелене коло з білими стрілками |
| Витрати | зелене коло з «+» | є (коло) | кільце навколо кнопки й поворот «+» |
| Шапка: профіль, лапка, дзвінок, налаштування | контурні | заповнених не потрібно | — |

Усі заповнені варіанти беруться з макета без перемальовування; інші іконки не змінюються.

## 4. Розбиття на підревізії

| Підревізія | Клас | Що | З макета / потрібне погодження |
|---|---|---|---|
| DS-3a | B | Заповнені іконки вибраної вкладки + кольори | з макета |
| DS-3b | C | Бульбашка 520 мс без перельоту, натиск .86, анімації іконок, `prefers-reduced-motion` | числа з макета; погодити, чи перемикати анімацію під час `switchTab` (поведінка перемикання не змінюється) |
| DS-3c | C | Стиснення таббару при прокрутці (mini) + взаємодія з `kb-*`, safe-area, iPad | **потрібне погодження** порогів (швидкість, відстань) і того, що mini не діє при відкритій клавіатурі |
| DS-3d | B | Скло банера, тосту, бічної панелі + вкладені радіуси (`.avatar-face`, `.pay-card-hit`, `.bank-badge-generic`) | з токенів DS-N1/N3 |
| DS-3e | C | Шапка: перемикач місяця «‹ ›», скляний список, рядок «Ви дивитесь минулий місяць» | **потрібне погодження**: майбутні місяці недоступні, джерело переліку місяців |
| DS-3f | C | Компактна шапка й капсула з місяцем при прокрутці | **потрібне погодження** порогу появи й спільного слухача прокрутки |

Порядок: a → d → b → e → c → f. Кожна підревізія окремий Rev; клас C = Крок 0 лише для c, e, f за потреби (b вже вписується в цей план).

## 5. Ключові сценарії (`docs/SCENARIOS.md`)

| Сценарій | Що перевірити | Спосіб |
|---|---|---|
| iPhone 390 pt | таббар, mini, шапка, капсула; знімки до/після | `e2e/ds-shots.spec.js` + пристрій |
| iPad | бічна панель без mini і бульбашки | знімок + ручна перевірка |
| Десктоп | таббар/панель, шапка | знімок |
| Темна й світла теми | скло, заповнені іконки, контраст | знімки обох тем |
| Офлайн | усе без мережі, список місяців із локальних даних | `e2e:smoke` в офлайні |
| Відкрита клавіатура | таббар ховається як зараз, mini не вмикається | клавіатурні тести 38–39 + пристрій |
| `prefers-reduced-motion` | анімацій немає, перемикання коректне | емуляція у Playwright |
| Перемикання місяців | стрілки, список, майбутні недоступні, минулий місяць із рядком | юніт-тест переліку місяців + E2E |

## Що потрібно від користувача

1. Погодити порядок підревізій (§4) і пороги mini/компактної шапки (c, f).
2. Підтвердити, що `<select>` місяця заміняється скляним списком (e) і що майбутні місяці недоступні.
3. Підтвердити, що на реальному iPhone перевіряються: мерехтіння blur при прокрутці, таббар при клавіатурі, нижній відступ (Баг 1a), іконки обох тем.
