# NO-OP-SAVE (Rev 2.32.220): аудит збережень без змін
| Форма / дія | «Зберегти» без змін | Було в функції | Стало |
|---|---|---|---|
| Редагування витрати в Журналі | неактивна (SAVE-DIRTY) | завжди `updatedAt`, `editedAt`-перевірка, push | без змін: лише закриття |
| Дохід (`ind-amount`) | неактивна | `updatedAt` + push навіть за тієї ж суми | та сама сума: нічого |
| Картка (форма + борг місяця) | неактивна | `updatedAt` картки й боргу завжди, push боргу | пишеться лише змінене; назва → каскад боргів зберігається |
| ОЧ (форма + борг місяця) | неактивна | те саме | пишеться лише змінене |
| Категорія / підкатегорія / слово (форма «Структури», редагування) | неактивна | `onSave` завжди | без змін: закриття форми |
| Створення (нова витрата, нова картка/ОЧ, слово) | завжди активна (нічого порівнювати) | — | без змін |
| Перемикачі налаштувань, автозбереження чернетки | локальні, на сервер не йдуть | — | без змін |
| Push витрат/доходів/боргів (`mdPushCas`) | — | пропускає запит, коли зліпок збігається | без змін |
Довідникові push (`push*Pilot` для довідників) відправляють лише dirty-записи (`updatedAt` ≠ `syncedUpdatedAt`), тож без зміни `updatedAt` запиту немає; `autoSyncStale` бере ті самі критерії.
