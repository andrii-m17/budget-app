# Rev 2.32.184 — ID-BIND-2 (Етап 2): групування боргів ОЧ за id

Не запушено до слова чату. Дані на сервері не чіпались.

## Зроблено
- `debtAccount` / `debtAccountKey` / `debtDisplayName` (`index.html`, перед `isHiddenForMonth`): ОЧ боргу за `accountId` → `cloudId`, запасний варіант — назва; осиротілий борг — окрема група.
- Групування за ключем: `debtTotalsForMonth`, `debtAsOfInfo`, `installmentChainSpec` (також витрати за `linkedInstallmentId`), `installmentStartMonth`.
- `cascadeInstallmentRename` у `pullInstallmentAccountsCore` (зміна назви ОЧ з сервера): борги, витрати, `hiddenFrom`, `ignoredDivergences`; лише локальні save, без `updatedAt` і push.
- Колізії (два активні борги ОЧ за місяць після каскаду) не зливаються; місяці в `lastRenameCollisions`.

## Тести

Усього 1797, 0 помилок.

## Відхилення і знахідки
- `installmentStartMonth` (Rev 2.32.179) шукала борги за назвою, тому ОЧ зі старими назвами ховалась у ранніх місяцях; виправлено зіставленням за id (знайшов тест).
- Тести 2.32.178 про «поля id лише записуються» переписано: тепер вони свідомо читаються в групуванні й каскаді; push-функції їх не читають.
