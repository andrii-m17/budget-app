# QA-1: «Чекліст перевірки» у «Тестування» (клас B, Rev 2.32.122, не запушено)

## Зроблено
- «Сервіс» → «Тестування» → «Чекліст перевірки»: пункти за ревізіями (з `qa.json`), для кожного кнопки «ок» / «не ок»; для «не ок» кнопки-причини «обрізано», «не працює», «повільно», «інше» (без текстового поля). Стан лише в `localStorage`; «Очистити пройдені» лишає «не ок».
- «Скопіювати результат»: `Збірка 2.32.122 · 22.10.2026` і рядок за номерами (`2.32.121-1 ок; 2.32.121-2 не ок: обрізано`); якщо буфер недоступний, текст у діалозі. Нічого не надсилається на сервер.
- `qa.json` генерує `scripts/gen-qa.mjs` зі звітів `docs/reports/*.md` (розділ «Для iPhone», пункти `Що перевірити: очікується`; ревізія з найближчого заголовка `Rev X.Y.Z`); `--check` перевіряє актуальність, тест `tests/qa.test.js` вимагає збігу. Поточна черга: URGENT-LOOP, HIDE-1, автор-колір, INCOME_SOURCES (9 пунктів). У `task-report` і `docs/WORKFLOW.md` додано правило «Для iPhone» для B/C.
- Запит `./qa.json?v=<версія>` з `cache:'no-store'`; у сервіс-воркері живе у кеші поточної версії (змінюється з кожним релізом).
- Клавіатурні правила й поля не чіпались.

## Перевірено
`node --test` зелений; `tests/qa.test.js` (6): ок/не ок/причини, текст результату, стан у `localStorage` (зіпсований, недоступний), фільтр пунктів, актуальність `qa.json`, відсутність мережі й полів. Один знімок розгорнутого чекліста (мок, темна тема): пункти, кнопки й причини вміщуються.

## Не перевірено
iPhone (прокрутка шторки, кнопки на дотик, копіювання в буфер).

## Rev 2.32.122: перевірка на пристрої

### Для iPhone
- Чекліст у «Тестування»: «Сервіс» → «Тестування» → «Показати чекліст перевірки»; пункти за ревізіями, кнопки «ок»/«не ок» і причини вміщуються, шторка прокручується
- «Скопіювати результат»: після кількох відповідей вставити текст у чат; формат `2.32.122-1 ок; … не ок: причина`

## Матриця сценаріїв (Rev 2.32.124)
| Сценарій | Перевірка |
|---|---|
| qa.json порожній / невалідний / 404 / офлайн | тест `loadQaItems`; повідомлення з порадою повторити, наступне відкриття перезавантажує |
| ≥ 10 пунктів в одній ревізії | тест gen-qa: числове сортування |
| Звіт з CRLF, багаторядковим пунктом, код-блоком | тест gen-qa |
| Текст пункту змінився | відповідь з іншим хешем не показується (тест `qaAnswerFor`) |
| Зіпсований localStorage, `__proto__` | тести стану |
| Дві ревізії з однаковим номером у різних звітах | унікальні id (тест) |
