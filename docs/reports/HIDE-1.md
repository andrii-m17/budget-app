# HIDE-1: «Приховувати суми й назви на екрані блокування» (клас B, Rev 2.32.109, не запушено)

## Зроблено
- Сервер (чат): `notification_settings.hide_details` (типово `false`), `push_send` підміняє текст; зафіксовано в `docs/SUPABASE_POLICY.md`.
- Клієнт: перемикач у «Налаштування → Сповіщення» під головним тумблером (та сама картка, без нової групи), підказка під карткою. Вигляд і поведінка як у наявних перемикачів. Типово вимкнено. Зберігається через `saveNotificationSetting({ hide_details })` (upsert власного рядка). Читається в `loadNotificationSettings` (відсутнє/`null` → `false`).
- Підпис довгий: у 400 pt шторці ховався під перемикачем; додано клас `n-row-wrap` (перенос на два рядки), висота рядка 52 pt.

## Перевірено
- `node --test`: зелено. Нові тести `tests/hide-details.test.js` (типове значення, місце рядка, читання з рядка, upsert з `{hide_details}` і відкат при помилці, розмітка й підказка); оновлено `tests/notifications.test.js` (порядок рядків, типові значення).
- Preview (мок): рядок і підказка на місці, підпис у два рядки; у моку дозвіл «denied», тому перемикачі приглушені.

## Не перевірено / ризики
- iPhone, реальна база (поле в таблиці є, перевірив лише читанням коду клієнта; сервер зробив чат), реальний текст push на екрані блокування.
- Realtime-синхронізації значення між двома пристроями немає (як і для решти налаштувань сповіщень): значення читається при відкритті екрана.

## iPhone
Увімкнути перемикач → надіслати тестове сповіщення/дочекатися реального → на екрані блокування загальний текст; вимкнути → повний текст; на другому пристрої після відкриття екрана значення збігається.
