# NOTIF-2: журнал сповіщень: старий вигляд + виправлення нагадування (клас B)

## Rev 2.32.102
### Підсумок
Вигляд повернуто до `rev-2.32.95`, поведінка Rev 3 збережена, нагадування відрізняється від пачки.

### Що зроблено
- Вигляд: без крапки, пілюль і підпису «джерело · час»; час праворуч; «Прочитати всі» у шапці, «Очистити архів» окремим рядком знизу (з підтвердженням); приглушення лише для не-«нових».
- Поведінка Rev 3 лишилась: свайп-видалення, кошик, один запит станів пачок, тап по обробленому за маршрутами, доступність.
- Нагадування: «нове», поки є `mono_inbox` зі `status='new'` за київську добу `created_at` нагадування (за `tx_time`); інакше «оброблено». Додатковий запит нових операцій тільки коли в списку є нагадування; помилка або ≥1000 рядків → стан за `read_at`. Тап по нагадуванню → «Вхідні» без підсвітки пачки.
- Сервер: прочитано лише визначення `mono_inbox_autoread` (читання), щоб звірити поле доби (`tx_time`, `Europe/Kyiv`). Нічого не змінював.

### Перевірено
- `node --test`: 1388 тестів, 1386 пройшли, 0 впали, 2 відомі todo. Нові: `isDailyReminderRow`, `kyivDateKey`, стани нагадування, запит нових операцій (доби по Києву), оновлені тести розмітки.
- Піксельне порівняння з `docs/ui/notif3-before-{dark,light}-390.png`: 0 відмінних пікселів (поріг 24 за сумою каналів; макс. 15), на зафіксованій даті 16.10.2026. Скрипт: `scripts/notif-history-shots.mjs after`.
- Ширини 290, 320, 360, 440: без виходу за межі й горизонтальної прокрутки; свайп відкриває «Видалити» 84 pt. Знімки `docs/ui/notif2-after-*`.

### Відхилення
- Для чесного порівняння в тестовій пачці №3 є непрочитана операція (інакше за новою логікою вона «оброблена» й приглушена, а в еталоні 2.32.95 її приглушення залежало лише від `read_at`).
- `html:root :is(.expense-row…)` давав рядкам світлу лінію й тінь (і в Rev 3); прибрано `box-shadow:none` вищої специфічності.

### Не перевірено / ризики
- iPhone не бачив. Справжній PostgREST із даними (`status=eq.new`, діапазон `tx_time`) не перевіряв.
- Нагадування за добу, у якій понад 1000 нових операцій, не визначиться (стан за `read_at`).

### Перевірка на iPhone
Журнал сповіщень: вигляд як до Rev 3 (час праворуч, без пілюль), «Очистити архів» знизу, «Прочитати всі» вгорі; свайп уліво видаляє одне; нагадування лишається яскравим, поки є нові операції тієї доби, і тап веде у «Вхідні».

## Rev 2.32.106: нагадування за read_at (рішення чату)

Тести: стани нагадування, `reminderPending`, тап (без нових / з новими / невідомо). Попутно (клас A): `prefers-reduced-motion` для `.app-modal`: затухання без масштабу (CDP: normal без змін).
