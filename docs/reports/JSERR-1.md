# JSERR-1: кільцевий журнал помилок JS в IndexedDB (клас B, Rev 2.32.123, не запушено)

## Зроблено
- Кільцевий журнал помилок JavaScript (≤ 50 унікальних) в окремій IndexedDB `budget-app-js-errors`, **лише за перемикачем розробника** (той самий, що «Розширена діагностика сповіщень»; вимкнено за замовчуванням: тоді нічого не пишеться і база не відкривається). Прапорець читається один раз на старті; при вмиканні поточні помилки сеансу скидаються в журнал.
- Запис: те, що вже обробляє `recordJsError` (повідомлення очищене до 160 символів без email і довгих чисел, `файл:рядок`, імена 3 кадрів, вкладка), без значень користувача; дублікат = `count` і час останньої появи; ліміт частоти ≤ 10 записів за хвилину; усе best-effort, винятків не кидає.
- Розробницькі кнопки (лише при увімкненому режимі): «Показати журнал помилок JS», «Очистити журнал помилок JS». «Надіслати лог сповіщень» тепер додає журнал помилок до подій воркера й знімка пристрою (події `js-error`).
- Основне не змінено: `onerror`/`unhandledrejection`, лічильник «Помилок за сеанс», буфер 20, події рекордера; додано лише один виклик `jsErrPersist(rec)` в `try`.

## Перевірено
`node --test` зелений; `tests/jserr-ring.test.js` (6): вимкнено = нічого й база не відкривається, увімкнено = обрізані поля без даних користувача, дублікат, кільце 50, ліміт частоти (10/хв), читання/очищення/збій IndexedDB, джерельні гарантії. Мок у браузері: вимкнено 0 записів; увімкнено: сеансові помилки скинуто, email і число в повідомленні замінені, дублікат `count 2`, лічильник сеансу без змін.

## Не перевірено
iPhone: чи помилка після закриття PWA лишається в журналі; відправка в `client_debug_logs` реальним входом.

## Рішення / ризики
Окрема база (не схема діагностики push), щоб не міняти версію бази, яку читає `sw.js`. Помилки до відповіді прапорця на старті (мілісекунди) не журналяться. Тексти помилок скрабляться, але повної гарантії відсутності фрагментів даних немає [Н].

## Rev 2.32.123: перевірка на пристрої

### Для iPhone
- Журнал помилок JS лише в режимі розробника: «Тестування» → «Розширена діагностика сповіщень» увімкнути, «Показати журнал помилок JS»: журнал порожній або з помилками без значень користувача
- «Надіслати лог сповіщень» з журналом помилок: надіслати лог; після відправки текст «Лог сповіщень надіслано», режим вимкнений: нічого не пишеться
