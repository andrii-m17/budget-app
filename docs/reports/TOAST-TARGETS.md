# TOAST-TARGETS — Rev 2.32.127 (клас B; не запушено)

## Зміни
- Поп-ап про дію іншого учасника (`showLiveToast`): видалення будь-якого домену → кнопка «Видалені» → «Сервіс» → «Видалені дані»; борги (не видалення) → «Борги» → «Облік» → «Борги»; решта → «Журнал». Поп-ап-зведення (`showSyncSummaryToast`): ціль, лише коли всі події ведуть в одне місце, інакше «Журнал». Узгоджено з маршрутами push (`routeForPushType`: `trash`, `debts`).
- Колір автора: нейтральний автор уже мав нейтральний колір у Журналі, «Видалених даних» і аватарі (`AUTHOR_NEUTRAL`); єдина прогалина — власний аватар без даних про автора фарбувався типовим зеленим, тепер нейтральним.
- Не змінено (для рішення): власні поп-апи про видалення («Видалено назавжди») показуються вже в «Видалених даних», кнопка зайва; поп-ап «Повернення враховано» (видалення витрати поверненням) без кнопки за рішенням FIX-UI-1a; іконка поп-апа про дії іншого учасника лишається синьою (`--color-info`) для всіх авторів, колір автора в ній не застосовується; видалений борг веде у «Видалені дані», а не в «Борги» (видалення має перевагу).
- Тести: `tests/toast-targets.test.js` (+4), `tests/success-toast.test.js` оновлено.

## Для iPhone
- Другий учасник видаляє витрату: поп-ап з кнопкою «Видалені» відкриває «Видалені дані»
- Другий учасник змінює борг: поп-ап з кнопкою «Борги» відкриває «Облік» → «Борги»
- Звичайна зміна витрати: кнопка лишається «Журнал»
