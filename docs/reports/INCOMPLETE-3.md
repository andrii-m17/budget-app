# INCOMPLETE-3 (клас C, Rev 2.32.150)

## Матриця сценаріїв (кожен рядок покритий у tests/incomplete-rules.test.js)
| Сутність | Стан | Місяць | Очікування |
|---|---|---|---|
| Картка | борг відомий = 0 | поточний/попередній | лише ліміт (якщо немає) |
| Картка | борг > 0, без мін. платежу й дня | поточний/попередній | minPayment, dueDay |
| Картка | борг > 0, мін. платіж 0 | поточний | лише dueDay (явний 0 знімає) |
| Картка | борг невідомий | поточний | balance, minPayment (залежний), dueDay |
| Картка | будь-який | старший/майбутній | лише ліміт |
| Картка | прихована/до createdAt | будь-який | [] |
| ОЧ | залишок ≤ 0 (закрита) | будь-який | [] |
| ОЧ | залишок > 0, платіж порожній/0 | поточний | payment / нічого |
| ОЧ | залишок невідомий | поточний | balance, payment (залежний) |
| ОЧ | будь-який | старший/майбутній | лише dueDay, initialAmount |
| ОЧ | прихована/до firstMonth | будь-який | [] |
| Вікно | грудень↔січень, без nowMonth | — | коректно / вікно вимкнене |

## Вплив
Лише відображення крапки/діалогу; дані, формули, синхронізація, сервер не змінені. Лічильники на сегментах «Борги»/«ОЧ» рахуються з тих самих функцій, тож зменшаться разом із крапками.
