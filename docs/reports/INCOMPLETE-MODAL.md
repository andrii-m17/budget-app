# INCOMPLETE-MODAL — Rev 2.32.130 (клас B; не запушено)

## Що
Модалка «Дані заповнені неповністю» за затвердженим макетом: заголовок (назва банку чи ОЧ, 16 px жирний), підзаголовок «Дані заповнені неповністю» (13 px приглушений), рядки «що бракує» з іконкою попередження (`--color-warning`), підписом ліворуч і приглушеним значенням праворуч (не вказано / немає даних), розділювач `--color-border`, висота рядка 44 px, переноси лише по пробілах. Кнопки «Закрити» і «Заповнити» без змін. Тексти через `textContent`.
- Таблиця підписів/значень: `incompleteRowModel(kind, reason)`; «День платежу» — картка, «Дата платежу» — ОЧ.
- Розміри з токенів модалок (`#app-modal`: 22px 20px, `--color-border`), не з цифр макета.
- Тести: `tests/incomplete-modal.test.js` (+3).

## Для iPhone
- «Облік» → «Борги»/«ОЧ»: тап по жовтій крапці картки/ОЧ відкриває модалку з назвою, підзаголовком і рядками «що бракує» (іконка, підпис, значення справа), без переносів посеред слова
- Кнопка «Заповнити» відкриває шторку з підсвіченим першим порожнім полем, «Закрити» закриває модалку
