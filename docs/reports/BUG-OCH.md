# BUG-OCH — Rev 2.32.125 (клас B; не запушено)

## Причина
`resolveInstallmentFact`: за прив'язаної витрати місяця береться лише оцінка `estimateInstallment().balance`; у перший місяць ОЧ (попереднього факту нема) вона `null`, і «Облік» показував «0 ₴», ігноруючи збережений факт. «Разом ОЧ» теж перетворювало `null` на 0. Збереження без початкової суми переривалось мовчки.

## Зміни
- Оцінки нема → показується збережений факт місяця; нема й факту → «—». Пріоритет прив'язаної витрати (6D.148) і формули не змінені.
- «Разом ОЧ» пропускає невідомі залишки; усі невідомі → «—».
- `saveInstallmentDrawer`: тост «Вкажіть початкову суму ОЧ…» замість тихої відмови.
- Тести: `tests/och-balance-null.test.js` (S1–S5, S1b, перевірка тексту «—»/тосту).

## Для iPhone
- «Облік» → «ОЧ», перший місяць ОЧ із прив'язаною витратою: залишок показує збережену суму, а не «0 ₴»
- ОЧ без залишку й без попереднього місяця: у рядку «—», у «Разом ОЧ» невідомі не додаються
- Шторка ОЧ з порожньою «початковою сумою» → «Зберегти»: з'являється повідомлення, шторка лишається
