# Міст чат ↔ Claude Code через Notion

## Навіщо
Без копіювання промтів і звітів. Ви лише запускаєте обидві сторони: «чат, оформи задачу» → у Claude Code «візьми задачу» → «чат, звіт готовий».

## Налаштування (≈ 15 хв, один раз)
1. **Notion:** окремий робочий простір або сторінка «Money Tree · Пульт» з базою «Задачі».
   Властивості: `Код` (текст), `Назва` (заголовок), `Клас` (A/B/C), `Статус` (Чернетка · Готово до роботи · У роботі · Чекає рішення · Звіт · Прийнято · Перевірка на iPhone · Закрито), `Rev` (текст), `Макет` (URL).
   Шаблон сторінки: розділи «ТЗ», «Крок 0», «Звіт», «Приймання», «iPhone».
2. **Чат (claude.ai):** підключити конектор Notion і дозволити доступ до «Пульта».
3. **Claude Code:** `claude mcp add --transport http notion https://mcp.notion.com/mcp`, потім `/mcp` і вхід через браузер.
4. **Перевірка:** чат створює тестову задачу «Перевірка мосту» → Claude Code ставить «У роботі» й пише «Звіт: міст працює» → чат читає.

## Ролі в сторінці
| Розділ | Пише |
|---|---|
| ТЗ, Приймання | чат |
| Крок 0, Звіт | Claude Code |
| iPhone | Користувач А (або вставка з «Скопіювати результат») |

## Безпека
- У Notion лише процес, жодних реальних даних бюджету.
- Повністю автоматичного обміну без вашого запуску немає й не потрібно: ваш запуск це запобіжник від неконтрольованих змін у робочому застосунку.
